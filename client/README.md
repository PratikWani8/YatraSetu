# YatraSetu - Frontend

Pilgrim safety and emergency management platform built with React and Vite.

## Tech Stack

* React
* Vite
* Tailwind CSS
* React Router
* Framer Motion
* Axios
* Lucide React
* React Hot Toast
* React Leaflet
* Recharts
* QR Code / QR Scanner

## Features

### Pilgrim

* Pilgrim registration
* QR-based pilgrim identification
* Pilgrim dashboard
* Medical information
* Emergency assistance
* Guardian-related workflows

### Volunteer

* Volunteer registration and login
* Volunteer dashboard
* Register pilgrims
* Scan pilgrim QR
* Medical emergency handling
* Volunteer assignments

### NGO / Relief Team

* NGO registration and login
* NGO dashboard
* Volunteer management
* Food distribution
* Water distribution
* Reports and analytics
* PDF and Excel export

### Weather Officer

* Weather dashboard
* Heatwave monitoring
* Rain alerts
* Wind alerts
* Weather advisories
* Pilgrim/volunteer location monitoring

### Hospital Dashboard

The hospital dashboard provides:

* Today's patients
* Critical cases
* Available beds
* Ambulance status
* Emergency alerts
* Recent patients
* Bed availability
* Ambulance requests
* Recent activities
* Quick actions
