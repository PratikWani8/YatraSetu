# YatraSetu — Backend

Backend for the YatraSetu pilgrim safety and emergency management platform.

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* bcrypt
* Socket.IO
* Multer
* REST APIs

## API Structure

```text
/api/auth
/api/auth/hospital
/api/auth/weather
/api/pilgrims
/api/qr
/api/volunteer
/api/ngo
/api/ngo/water-distribution
/api/ngo/food-distribution
/api/ngo/reports
/api/missing-persons
```
